# Test states

These state files were mostly generated by the DM41L and used to understand
the memory architecture of the DM41L and the HP41C/CV/CX. Later they
were used by the unit tests to verify that DM41L_Explorer is functioning
correctly.

* 3x-xm.dm41: Contains 3 XM files: one DATA file, one ASCII file, and one
  Program file.
* 4alarmtest.dm41: Contains 4 different types of alarms: past due, control,
  conditional, repeating.
* 6x-xm.dm41: Contains 6 XM files: four DATA files, one ASCII file, and one
  Program file.
* alarmtest*.dm41: different examples of alarms.
* badalarms.dm41: a malformed alarms file created by an attempt to delete an
  alarm.
* delfl-xm.dm41: 6x-xm.dm41 with one file deleted.
* empty.dm41: A memory state of a DM41L in the MEMORY LOST condition.
* empty-128.dm41: A memory state of a blank DM41L that has had the number of
  data registers set to 128.
* fillextended.dm41: Contains a small app called FILL and a large ASCII file
  meant to consume all extended memory.
* global-key-assignments.dm41: Contains two small apps that have been assigned
  to keys.
* goodalarms.dm41: The alarms file badalarms was derived from.
* helloworld.dm41: A small memory state containing a single XM ASCII file
  containing two records: "HELLO" and "WORLD".
* keyassigns.dm41: Sample key assignments, containing only built-in functions.
* lander*dm41: a sample application in packed and unpacked forms.
* manyfiles.dm41: Contains several XM files and programs, including a mix of
  both storage mechanisms for key assignments -- global-program assignments
  (XMBCD/XMALPHA/PURXM, keys 11/12/13 unshifted) alongside built-in/peripheral
  ones (EMROOM/XTOA, keys 14/15 unshifted) -- useful for testing that both
  kinds are handled correctly in the same state.
* numtest.dm41: Simple test app to illustrate how BCD numbers are encoded in
  apps.
* past-due.dm41: A collection of alarms deliberately allowed to enter "past
  due" state.
* PK-UP.dat, PK-UP.txt: Samples for testing synthetic programming support.
* repeater.dm41: a repeating alarm.
* samplelabels.dm41: A program consisting of single character labels to test
  how they are stored.
* simple.dm41: Has a single program called "APPTEST".
* targ*dm41: Another sample app stored in packed and unpacked forms.
* tenthsofasecond.dm41: Sample alarm for testing the resolution of alarms.
* tower.*: Another sample app for testing import/export.
* twolabels.dm41: An app with two global labels.
* unlabelled.dm41: Two apps with no global labels at all.
* xrom-keyassignments.dm41: Used both to test key assignments to external rom
  functions and to test a bug fix involving key assignments to row 4.
